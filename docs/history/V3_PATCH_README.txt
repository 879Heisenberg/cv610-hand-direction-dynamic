轨迹优化补丁 v3（累积版）
===========================

用途：
1. 包含 v2 的跟踪、轨迹异常点过滤及显示裁剪边界保护。
2. 轨迹仅在 HAND_ENGINE_CAPTURING（手势采集中）显示。
3. 一旦识别完成进入 HAND_ENGINE_COOLDOWN，立即清空显示轨迹。
4. 等待激活、等待手部及冷却阶段均不显示轨迹。
5. 采集中丢失一帧检测时，显示轨迹断开；恢复检测后从新点重新开始，
   不跨越丢帧区间连接旧轨迹。
6. snapshot 层再次限制只有 CAPTURING 且最近检测仍有效时才输出轨迹。

安装：
将压缩包中的 hand_direction/ 目录覆盖到工程根目录对应位置。
这是累积版，包含 v2 修改，不需要先单独应用 v2。

验证：
PC CMake 构建通过，CTest 4/4 通过。
CV610 专用 DRM 显示路径仍需在目标板上实机验证。
